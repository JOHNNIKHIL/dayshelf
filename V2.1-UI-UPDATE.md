# DayShelf V2.1 — Journal UX + Visual Analytics

This is an overlay update for the existing DayShelf V2 project.

## Changes
- Reworked daily metric input from native `<select>` controls into interactive 1–5 scale buttons.
- Added descriptive metric labels and current-value badges.
- Added date jump control to the journal header.
- Reworked timeline into a vertical visual timeline.
- Added proper time input, category, details, quick Morning/Afternoon/Evening time presets.
- Added empty-state treatment for the timeline.
- Added daily visual analytics: mood, energy, stress, productivity, social, sleep, plan completion trends.
- Added a daily balance radar visualization.
- Added animations and reduced-motion support.
- Added a richer `/insights` page using the same visual analytics.

## Apply
Extract over the current V2 project.

Then run:

    npm run db:generate
    npm run build

No new database migration is required for this V2.1 update.
